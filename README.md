## 双 ISP 到底怎么验，别只看商家截图

住宅 IP 市场最常见的手法，是拿机房广播段伪装成家宽段，检测工具单一维度显示 ISP 就敢标「双 ISP」。判断标准其实只有一条：**Company 类型显示为 ISP，同时 ASN 类型也显示为 ISP**，两个维度相互印证才算完整的双 ISP。只满足一个的，大概率是广播段。

到手之后的验真顺序：

1. **多个 IP 检测工具交叉验证。** 单一工具的结果容易被针对性优化，两三个工具结论一致才有参考价值。
2. **查 IP 注册信息和路由轨迹。** 真住宅 IP 的归属链路能对应到当地运营商的宽带网络，路由上不会一路都是数据中心节点。
3. **看商家的资源获取方式。** 直接拉当地宽带到机房的真实性最高，靠广播段转售的经不起业务环境实测。
4. **拿真实业务环境跑一遍。** 假住宅 IP 在风控严格的平台上用不了多久就会露馅，这一步没有替代方案。

## 常见问题

**美国住宅 IP VPS 和普通美国 VPS 差在哪？**
普通 VPS 分的是数据中心机房段 IP，平台查一下 ASN 就知道是服务器环境。住宅 IP VPS 分的是美国当地运营商家庭宽带段的 IP，网络身份更接近普通居民用户。做跨境电商、社媒账号运营这类对登录环境敏感的业务，差别就体现在验证频率和限流概率上。

**「双 ISP」是两家运营商的网？**
不是。它指这个 IP 同时具备两个 ISP 属性标记，检测时 Company 和 ASN 两个维度都显示为 ISP，可信度比单 ISP 高，过风控的能力也更强。

**1.5TB 月流量够用吗？**
账号运营、发帖、日常后台管理这类操作，一个月很难接近 1.5TB。真正吃流量的是素材批量上传下载、视频推流和采集，这几类业务要按实际码率和时长算，跑超了就是 3M 限速。

**超流量之后会停机吗？**
不会，限速 3M。账号还能保持在线，但不要再指望它跑大流量任务。

**能用 shadowsocks 吗？**
不能，官网明确禁止，搭建方式指向官方教程。

**最便宜的 AUD$12.90 和 AUD$15.90 差 3 澳元，值不值？**
你跑直播、或者对晚高峰的稳定性有要求，值。只养号、跑 ChatGPT 固定出口，这 3 澳元省下来，先把 IP 验清楚更要紧。
